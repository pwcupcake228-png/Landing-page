# Nothing Product Landing Page

A responsive one-page landing page presenting Nothing products and brand information.

## Live Preview

[Open the live website](https://pwcupcake228-png.github.io/Landing-page/)

## Design Reference

[View the Figma design](https://www.figma.com/design/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?node-id=6802-139&p=f&t=Oo0ibN8VyNDBsN9o-0)

## Technologies

- HTML
- SCSS
- JavaScript
- Parcel

## Getting Started

Clone the repository and install its dependencies:

```bash
git clone https://github.com/pwcupcake228-png/Landing-page.git
cd Landing-page
npm install
```

Start the local development server:

```bash
npm start
```

## Features

- Responsive layout for desktop and mobile screens
- Featured product cards
- Navigation links to page sections
- Contact section with a form and contact details
